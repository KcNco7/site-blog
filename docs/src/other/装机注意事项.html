配置各种环境 ​

系统安装与数据恢复 ​

  1. 装机前请务必确保所有文件进行备份！装机前请务必确保所有文件进行备份！装机前请务必确保所有文件进行备份！
  2. 确定需要安装的操作系统版本
  3. 使用 Ventoy 制作启动 U 盘并安装系统。首次把 Ventoy 安装到 U 盘会格式化目标盘并清除其中的数据，操作前必须核对磁盘并备份；启动盘本身也不能替代镜像来源、校验和备份等安全措施
  4. 安装完成后，从 Windows Update 或设备厂商官网安装显卡、声卡、网卡等驱动。BIOS/UEFI 属于固件而不是驱动，只在确有需要时按设备型号和厂商说明更新
  5. 下载常用软件
  6. 恢复备份数据
  7. 配置开发环境

开发环境配置 ​

  1. VSCode 下载地址：https://code.visualstudio.com/ 插件用微软账户同步
  2. Node.js 从官网或受信任的版本管理工具安装。npm/pnpm 缓存应放在当前用户可写目录，不要为了绕过权限问题给缓存目录或系统目录授予 Everyone“完全控制”
  3. Git 下载地址：https://git-scm.com/install/windows
    • 可设置为中文界面
  4. Docker Desktop（可使用 WSL 2 后端）
    • 先核对当前 Docker Desktop 的 Windows、WSL、内存和硬件虚拟化要求，启用并更新 WSL 2
    • 下载Docker Desktop：https://www.docker.com/products/docker-desktop
    • 安装时按需要选择 WSL 2 或 Hyper-V 后端；完成后启动 Docker Desktop 并确认许可与运行状态
    • 在docker中安装具体镜像详见语雀文档
  5. Java环境配置 在windows上实现多个java jdk的共存解决办法_电脑上同时有java和jdk_ximeneschen的博客-CSDN博客
  6. JetBrains 直接安装JetBrains Toolbox 需要调整软件的默认安装位置
  7. VMware
    • 安装 Windows 虚拟机通常应使用可启动的 ISO 镜像。ESD 常是 Windows 映像文件而不是可直接引导的安装介质；只有 ESD 时，应先制作合规的可启动 ISO。虚拟机选择 BIOS 还是 UEFI 要与安装介质、系统版本和分区方式匹配，不存在“一律选择 BIOS，否则安装失败”的规则
    • 虚拟机安装Ubuntu live-server https://blog.csdn.net/weixin_45039768/article/details/129380111
  8. Xshell Xftp 下载地址：https://www.xshell.com/zh/free-for-home-school/
  9. Go语言安装:
    • 从 Go 官网下载安装程序或压缩包，并按所选安装方式配置环境
    • 具体看：配置 Go 环境变量

Windows Terminal 美化 ​

  1. 微软应用商店搜索安装 Windows Terminal

  2. 可以在设置界面修改，也可以打开 settings.json。下面示例把亚克力效果、20% 不透明度和 16 磅字号应用到所有配置文件；opacity 是当前属性，旧的 acrylicOpacity 仅用于兼容旧版：

jsonc
{
  "initialCols": 100,
  "initialRows": 30,
  "centerOnLaunch": true,
  "profiles": {
    "defaults": {
      "useAcrylic": true,
      "opacity": 20,
      "font": {
        "size": 16
      }
    },
    "list": [
      // 保留 settings.json 中现有的配置文件
    ]
  }
}
