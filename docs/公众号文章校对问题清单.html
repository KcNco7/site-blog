01｜HTML ​

  • 01：把“块级/行内元素”当成 HTML 内容模型，概念混淆；现代 HTML 的内容分类不能用这组旧式显示分类替代。
  • 02：根相对路径解释不完整；把 track 当成 video 属性；表格示例和 caption、thead、行组说明有误；iframe 使用了过时属性。
  • 03：出现不存在的 <reset> 标签；checked、selected 的含义及重复使用说明不准确；textarea 不支持文中所写的 min、max。
  • 04：ARIA 使用过度；div role="button" 示例缺少键盘与焦点支持；aria-haspopup 的使用场景不准确。

02｜CSS ​

  • 01：层叠优先级漏掉来源、!important 和层叠层；initial、unset、revert 的解释错误；@layer 说明不完整。
  • 02：fontfamily 拼写错误；@font-face 示例缺少分号；默认字号不保证是 16px；:where()、:is() 权重说明错误；多个伪类缺少冒号。
  • 03：width 的初始值是 auto，不是固定 100%；高度类比不成立；边框默认值解释错误；border-box 说明写反；overflow 初始值不是 auto。
  • 04：绝对定位和固定定位的包含块规则过度简化；遗漏 transform 等会建立包含块的情况；z-index:auto 不是 1；sticky 与层叠上下文说明不准确。
  • 05：存在 gird-auto-flow、justfy-items 拼写错误；对齐属性混用；隐式网格与 grid-template-areas 说明有误。
  • 06：flex-grow、flex-shrink 的计算被过度简化；出现无效 </>；inline-flex、inline-grid 的行为解释错误；BFC 的作用被夸大。
  • 07：box-shadow 语法以及 blur/spread 含义有误；drop-shadow() 的说明不准确。
  • 08：transform 函数执行顺序写反；把 position 与 transform 的职责混淆；颜色与导航部分仍是空内容。

03｜JavaScript 基础 ​

  • 01：“用 Java 语法写 JavaScript”的说法错误；相等比较和 NaN 判断有误；对象字面量缺少逗号。
  • 02：代码块混入未注释中文；遗漏 Symbol 键；把 map.set() 当成读取方法；称 Set 为“无序”不严谨；Generator 部分为空。
  • 03：块级作用域说明不全；let 的提升与暂时性死区解释错误；函数表达式和 Date 示例有误；“所有值都是对象/JSON”错误；重复及未声明变量会导致代码失败。
  • 04：原型与 __proto__ 说明不准确；this 规则过度简化；把 apply 写成 call；遗漏 bind 的预置参数能力。
  • 05：Promise 状态术语有误；ES 模块支持顶层 await；代码块混入未注释正文。
  • 06：getAttribute 示例目标不存在；DocumentFragment 不保证完全没有重排；DOM 操作不一定都立即触发回流；表单部分不完整。
  • 07：“Node 不支持 ESM”的表述已过时；namespace import 被错误命名。
  • 08：示例调用未定义的 __debounce、__throttle，且正文残缺。
  • 09：同一作用域重复声明常量和函数；代码块混入中文；顶层 this 的结论只适用于经典脚本，不适用于模块。

04｜JavaScript 常用 API ​

  • 01：并非所有字符串方法都返回字符串或“新字符串”；charCodeAt() 返回 UTF-16 code unit，不是 ASCII 码。
  • 02：多个数组示例错误地使用逗号运算符，所谓“连续访问”结论不成立。
  • 03：Object.keys/values/entries 只处理自有、可枚举、字符串键；Object.freeze() 是浅冻结。
  • 04：查询字符串拼接未做编码，遇到特殊字符会出错。
  • 05：内容重复；多处方法返回值结论错误；“对象所有键”说法过宽；Object.is() 不能简单概括为“比严格相等更严格”。

05｜浏览器运行机制 ​

  • 01：把 Promise 回调归为宏任务；把 Promise.resolve() 本身当作任务；把 requestAnimationFrame 简单归为宏任务，均不准确。
  • 02：回流、重绘和合成的触发关系写得过于绝对。
  • 03：只有图片，没有解释 defer、async 与模块脚本的真实执行差异。

06｜HTTP、AJAX、Fetch 与 Axios ​

  • 01：XHR 数据方向和 readyState 说明错误；Axios 不是简单的“Fetch/XHR 统一封装”；Fetch 示例没有检查 response.ok。
  • 02：Axios 不会自动取消重复请求；innerHTML 示例有 XSS 风险；JSON.parse 异常没有进入预期的 Promise 拒绝流程。
  • 03：封装实例未导出，示例 API 不完整。
  • 04：响应拦截器已经返回 res.data，静态类型却仍按 AxiosResponse/自定义 Promise<T> 处理，运行值与类型不一致。

07｜Git ​

  • 01：user.password 不是 Git 的有效身份配置；reflog 不是每次文件编辑记录；多个 reset/rm/恢复命令解释错误且可能误导删除；存在命令拼写问题。
  • 02：clone URL 中有无效空格；master、main 混用；括号中的“命令”不可执行；把 pull 简化为固定行为；upstream 语法混用。

08｜Node.js 基础 ​

  • 02：多个 pnpm workspace 命令被写成等价行为；store/cache、prune、status 的含义不准确；“Monorepo 第一选择”等结论缺少依据。
  • 03：Express 只有占位内容，保持“待补充”。

09｜包管理与工程脚本 ​

  • 02：Oxlint 插件职责写错；配置互相矛盾且有缺项。

  • 03：类、元组、枚举、Symbol、迭代器示例中存在大量编译错误；super、只读元组、extends、symbol 键等说明有误。

  • 08：typeof 对函数的结果、类型谓词与重复声明有误；协变/逆变方向写反；ReturnType 示例语法错误。

16｜Pinia ​

  • 01：缺少导入；patch 示例使用未声明的 school；store 文件名不是框架硬性要求。
  • 02：localStorage 写入与读取的 key 不一致；使用上下文有误；getter 后有错误分号。
  • 03：重复定义 store；state 写法错误；使用未声明的 age；重复常量导致编译失败。

17｜Vue Router ​

  • 01：导入 News 却未注册为路由；嵌套路由对应的 <router-view> 放置错误。
  • 02：query 字符串格式错误且未编码；重复 params 可能是数组；三种 props 配置被同时写成一个路由；组合式守卫并不替代全部全局守卫。
  • 03：hash 模式不是默认模式。
  • 04：未声明的任意 params 会被丢弃；命名路由可以同时带 query；path 中的 params 会保留；代码有语法错误，且五个小节仍为空。

18｜React ​

  • 01：useFormStatus 来自 react-dom；设置相同 state 可能跳过渲染；map、dangerouslySetInnerHTML 示例无效；SWC 和模块打包说明有误。
  • 02：useReducer 不是“解决 state 同步”的 API；setAge 示例结论过度绝对；有未声明变量、reducer 直接修改与类型错误。
  • 03：localStorage 的 getSnapshot 每次创建新对象会导致订阅问题；React 19 中 startTransition 的“必须同步调用”说法已过时。
  • 04：effect 执行时机和清理说明错误；SWR 数据处理、解构与可选链示例有误；useLayoutEffect/useEffect 对比过于绝对。
  • 05：ref 作为依赖的结论过度泛化；React 19 中 forwardRef 已不再是新代码必需方案；Provider 并未移除；useDebugValue 返回值和 useCallback 说明有误。
  • 06：Suspense 不能自动接管任意请求或图片；HOC 定义不准确。
  • 07：styled-components 全局 CSS 示例含无效逗号。
  • 08：NavLink 可用于布局；index/prefix 路由说明混乱；混入 Vue Router；StaticRouter/Next.js 内容不准确；React Router 模式推荐已过时。
  • 09：CSS 写成无效 animate；相对导航说明有误；shell 代码块含反引号问题；TanStack Router 并不强制固定 routes 文件夹。
  • 10：Zustand get 不接收 state 参数；Vue 集成不是官方核心能力；深层更新、Immer、浅比较、render 中订阅与默认相等比较说明均有误。

19｜Next.js ​

  • 01：Turbopack “10 倍/700 倍”缺少可靠依据；React Compiler 需要安装并显式配置；并非 app 下每个文件夹都会形成公开路由。
  • 02：Link prefetch 规则更细；静态生产渲染下 useSearchParams 才涉及特定 Suspense 要求；permanentRedirect 后代码不可达；平行路由 slot 的特殊文件名应为小写，Nav 只是普通组件。
  • 03：route.ts 只能位于 app 路由树中，不是项目任意位置；httpOnly 解释不准确。
  • 04：JSON 代码块含注释，不是合法 JSON；key 和本地文件处理有问题；AI SDK 示例需要固定版本后再验证。
  • 05：Proxy 不能按文中方式任意修改响应正文；CSR/SSR/SSG 的框架分类过度绝对；水合前 HTML 仍可具有原生交互。
  • 06：RSC 不是 React 19 才出现；不能简单等同“服务端渲染/客户端渲染”；Client Component 可通过 children 接收 Server Component；JS、DOM、BOM 的教学定义不准确。
  • 07：开启 Cache Components 不会让“所有组件都动态化”；缓存边界和默认行为说明不准确。
  • 08：动态 await import 示例不受支持；APNG、eager/preload、AVIF 和可变字体结论过度泛化；Script 注入位置、blocking、remote id、onLoad 大小写以及 client 边界说明有误。
  • 09：distDir 是 Next 构建目录，不是静态导出目录；自定义图片 loader 忽略 width/quality；MD/MDX 配置有遗漏；执行不可信 MDX 有安全风险。
  • 10：Server Functions 的范围比正文更广；列表格式错误；鉴权边界缺失。
  • 11：locale 与 q 参数解释错误；defaultLocale 不能是数组；字典导入前后不一致；proxy 文件位置/扩展名错误；根路由不会按示例自动跳转。
  • 12：“提升 50%”无依据；phase 常量疑似写错；JSON 示例含注释；distDir、pageExtensions、ETag、Sass 依赖说明有误。
  • 13：搜索引擎优先级结论自相矛盾；generateSitemaps 不会自动生成根 sitemap 索引；local 拼写错误；metadata 的 openGraph 是浅合并；JSON-LD 对象与类型不匹配；Lighthouse 中没有文中所写的 INP 字段。
  • 14：cuid 不是自增字段；updatedAt 说明不完整；数据库名称前后不一致并含弯引号；密码明文存储；连接单例和开发连接处理有问题。

30｜Go 语言基础 ​

  • 05：type myint int 是新定义类型而非别名；Go 没有 class/继承，嵌入是组合和成员提升；未导出字段是包内可见；接口不是“本质上的指针”。
  • 06：接口的动态 pair 不能泛化到所有变量；终端示例不跨平台且文件未关闭；反射可能 panic；omitempty 与零值说明有误；不存在顶层 json.Decode；泛型零开销、any 装箱和固定优先级均过度绝对；约束示例过时。
  • 07：用 time.Sleep 等待 goroutine 不可靠；WaitGroup 是完成同步，不是数据通信；GMP 图过度简化；共享数据还可用原子等同步手段。
  • 08：已关闭但缓冲区未清空时，接收的 ok 仍为 true；并非所有 channel 都要关闭；重复 ctx := 不能编译；取消说明不精确；WithValue 写入和读取 key 类型不同，结果必为 nil。
  • 09：GOPATH 并未完全淘汰；IDE 不保证自动创建 go.mod；vendor/verify 说明过宽；直接手改 require 不应作为等价首选；replace 示例格式无效。
