## Windows Terminal 美化

1. 微软应用商店搜索安装 Windows Terminal

2. 可以在设置界面修改，也可以打开 `settings.json`。下面示例把亚克力效果、20% 不透明度和 16 磅字号应用到所有配置文件；`opacity` 是当前属性，旧的 `acrylicOpacity` 仅用于兼容旧版：

```jsonc
{
  "initialCols": 100,
  "initialRows": 30,
  "centerOnLaunch": true,
  "profiles": {
    "defaults": {
      "useAcrylic": true,
      "opacity": 20,
      "font": {
        "size": 16
      }
    },
    "list": [
      // 保留 settings.json 中现有的配置文件
    ]
  }
}
```

3. `initialCols`、`initialRows` 和 `centerOnLaunch` 是根级启动设置，分别控制初始列数、行数和启动时居中。
