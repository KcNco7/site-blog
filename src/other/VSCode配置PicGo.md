在 VS Code 中使用 PicGo 插件，可以通过快捷键将截图或本地图片一键上传至图床，并自动生成 Markdown 链接插入文档中。安装与基本配置安装插件：打开 VS Code，点击左侧扩展图标，搜索 PicGo 并点击安装。配置图床：点击 VS Code 左下角齿轮（设置）-> 设置，搜索 picgo。选择你使用的图床类型（如 GitHub、阿里云 OSS、腾讯云 等）并填入对应的参数（如仓库名、分支、Token/密钥等）。常用快捷键与使用方法配置完成后，在编写 Markdown 时主要有以下几种上传方式：剪贴板上传（最常用）：复制或截图一张图片到剪贴板，按下快捷键 Ctrl + Alt + U（Windows/Linux）或 Cmd + Option + U（Mac），图片会自动上传并插入 Markdown 语法链接。资源管理器选择上传：按下 Ctrl + Alt + E（Windows/Linux），在弹出窗口中选择本地图片进行上传。输入路径上传：按下 Ctrl + Alt + O（Windows/Linux），通过输入文件路径上传。
