## SEO(搜索引擎优化)

SEO（Search Engine Optimization）是改善网站内容、技术结构和可发现性的持续过程，目标是帮助搜索引擎正确抓取、理解和呈现页面，并吸引与内容相关的自然搜索流量。搜索引擎负责抓取、索引和排序；SEO 只能提高被理解和展示的机会，不能保证收录或排名。

Next.js 提供服务端渲染、静态生成、Metadata API、sitemap 和 robots 等能力，便于实现技术 SEO；最终效果仍取决于内容质量、可抓取性、页面体验和部署配置。

- 黑帽 SEO：通常指使用违反搜索引擎规则的手段操纵排名，例如关键词堆砌、隐藏文本和欺诈性链接。
- 白帽SEO：遵循搜索引擎的规则进行优化，注重网站内容的质量，通过提高网站的用户体验来赢得更好的排名。

## TDK(Title Description Keywords)

TDK 是 Title、Description、Keywords 的缩写，分别对应页面标题、摘要和关键词元数据。

在 Next.js App Router 中，可以通过静态 `metadata` 对象或动态 `generateMetadata` 函数设置这些字段。标题和描述会影响搜索结果的呈现，但搜索引擎可能改写它们；主流搜索引擎通常不会把 `meta keywords` 作为重要排名信号。

## SSG SPA SSR

SSG（Static Site Generation，静态站点生成）是在构建阶段预先生成 HTML，部署后通常由静态服务器或 CDN 直接提供。VitePress、Astro 等工具支持这种模式，常用于官网、营销页、博客和技术文档。SSG 也可以在浏览器加载后继续运行 JavaScript，并不意味着页面一定没有交互。

SPA（Single-Page Application，单页应用）通常只在首次导航时加载一个主要 HTML 文档，后续路由切换由客户端 JavaScript 更新界面和历史记录，避免整页刷新。它描述的是客户端导航模型，不等于页面只能有一个组件或只能请求一次数据。

SSR（Server-Side Rendering，服务端渲染）是在请求到达时由服务器生成当前页面 HTML，再发送给浏览器。SSR、SSG 和 SPA 是不同维度的渲染与导航策略，不能写成“SSR = SPA + SSG”；一个应用可以按路由混合使用 SSR、SSG，并在客户端水合后提供 SPA 式导航。

## 事件代理

事件代理（Event Delegation）是一种把事件监听器设置在共同祖先元素上，并根据实际事件目标统一处理后代元素事件的模式。它通常用于减少重复监听器。

### 事件传播与目标元素

DOM 事件传播通常包括捕获阶段、目标阶段和冒泡阶段。常见的事件代理利用冒泡阶段；根据事件类型和实际需求，也可以在捕获阶段设置监听器。

并非所有事件都会冒泡。例如，`focus`、`blur`、`mouseenter`、`mouseleave` 和 `load` 等事件不会像 `click` 一样冒泡，使用事件代理前应确认事件的 `bubbles` 行为。

- `event.target`：最初触发事件的元素。
- `event.currentTarget`：当前事件监听器绑定的元素。

如果可操作元素中包含图标、文本等嵌套节点，`event.target` 可能是这些内部节点。可以使用 `closest()` 查找目标元素，并确认它确实位于代理容器中：

```js
const list = document.querySelector(".list");

list.addEventListener("click", (event) => {
  const item = event.target.closest("[data-action]");

  if (!item || !event.currentTarget.contains(item)) return;

  console.log(item.dataset.action);
});
```

## 回流与重绘

布局（Layout，也常称 Reflow）负责计算元素的尺寸和位置；影响几何信息的变化可能使浏览器重新执行布局。

绘制（Paint，也常称 Repaint）负责把文字、颜色、边框、阴影等视觉内容转换为像素；不影响几何信息的视觉变化可能跳过布局，但仍需要重新绘制。

典型渲染路径是样式计算 → 布局 → 绘制 → 合成，但浏览器会按受影响范围进行优化，具体执行哪些阶段取决于属性、图层和浏览器实现。

### 合成与强制同步布局

某些已经独立分层的元素在修改 `transform`、`opacity` 等属性时，浏览器可能只需要更新合成结果，而不必重新执行布局或绘制。

JavaScript 修改样式后立即读取元素尺寸或位置，可能迫使浏览器提前执行同步布局。频繁交替执行“写样式”和“读布局”会形成 layout thrashing；实际开发中应尽量批量读取布局信息，再批量修改样式。

## defer 和 async

![defer](/assert/knowledge-image/defer.jpeg)

### 普通脚本、defer、async 与模块脚本

| 写法 | 下载与执行时机 | 执行顺序 | 与 `DOMContentLoaded` 的关系 |
| --- | --- | --- | --- |
| `<script src="./blocking.js"></script>` | 解析器遇到脚本后通常暂停 HTML 解析，等待脚本获取并执行 | 按文档中的出现顺序 | 脚本执行完成后，浏览器才会继续解析后续 HTML |
| `<script defer src="./app.js"></script>` | 与 HTML 解析并行获取，在文档解析完成后执行 | 多个 `defer` 脚本按文档顺序执行 | `DOMContentLoaded` 会等待它们执行完成 |
| `<script async src="./analytics.js"></script>` | 与 HTML 解析并行获取，脚本可用后尽快执行；执行时仍会暂停 HTML 解析 | 不保证文档顺序 | `async` 脚本不是 `DOMContentLoaded` 的等待条件 |
| `<script type="module" src="./main.js"></script>` | 获取入口模块及其依赖；未使用 `async` 时默认采用延后执行方式 | 按模块依赖关系完成链接和求值 | `DOMContentLoaded` 会等待模块脚本执行完成 |

`defer` 主要用于带 `src` 的经典外部脚本；用于内联经典脚本时没有效果，模块脚本本身则默认延后执行。`async` 更适合彼此独立、无需依赖其他脚本或完整 DOM 的代码。给模块脚本添加 `async` 后，浏览器会在模块及其依赖可用时尽快执行，不再保证与其他脚本的相对顺序。

```html
<script src="./blocking.js"></script>
<script defer src="./app.js"></script>
<script async src="./analytics.js"></script>
<script type="module" src="./main.js"></script>
```

## `import A from 'C'`和 `import { B } from 'C'` 有什么区别?

`import A from 'C'` 导入的是模块 C 的默认导出（export default），A 是你给它起的任意名字。

`import { B } from 'C'` 导入的是模块 C 的具名导出（export），B 必须和导出时的名字一致。

```javascript
// C.js
export default function foo() {} // 默认导出
export function bar() {} // 具名导出
```

```javascript
// main.js
import Whatever from "./C.js"; // 绑定到 C.js 的默认导出，本地名称可以自行命名
import { bar } from "./C.js"; // 具名导入；也可以使用 import { bar as baz } 重命名
```

- 一个模块只能有一个 `export default`，但可以有多个 `export`。
- 默认导出本质上是一个名为 `default` 的具名导出，所以 `import { default as A } from "./C.js"` 等价于 `import A from "./C.js"`。
- 两者可以混用：`import A, { B } from "./C.js"`。

### 模块导入补充

静态 `import` 声明只能出现在模块的顶层。在浏览器中，需要通过 `<script type="module">` 或另一个模块文件使用；导入得到的是只读的实时绑定，导出模块更新对应值后，导入侧可以观察到新值，但不能直接给导入绑定重新赋值。

浏览器通常直接解析相对 URL、根相对 URL 和绝对 URL。像 `"C"` 这样不以 `/`、`./` 或 `../` 开头的写法属于裸模块说明符，通常需要 import map、构建工具或运行环境提供解析规则。

除默认导入和具名导入外，还可以使用命名空间导入、副作用导入和动态导入：

```js
import * as moduleC from "./C.js";
import "./polyfill.js";

const featureModule = await import("./feature.js");
```

`import()` 返回 Promise，适合按条件或按需加载模块；示例中的顶层 `await` 需要在模块环境中使用。

## 字符串 数组 对象 方法总结

### 一、字符串方法（String）

> **特点：字符串是不可变的**
> 字符串方法不会修改原字符串；不同方法可能返回字符串、数字、布尔值、数组或其他结果。

#### 1. 常用字符串方法

| 方法                     | 作用                 | 示例                           | 返回值          |
| ------------------------ | -------------------- | ------------------------------ | --------------- |
| `trim()`                 | 去掉两端空白         | `"  hi  ".trim()`              | `"hi"`          |
| `trimStart()`            | 去掉开头空白         | `"  hi".trimStart()`           | `"hi"`          |
| `trimEnd()`              | 去掉结尾空白         | `"hi  ".trimEnd()`             | `"hi"`          |
| `toUpperCase()`          | 转大写               | `"abc".toUpperCase()`          | `"ABC"`         |
| `toLowerCase()`          | 转小写               | `"ABC".toLowerCase()`          | `"abc"`         |
| `includes()`             | 是否包含某字符串     | `"hello".includes("ell")`      | `true`          |
| `startsWith()`           | 是否以某字符串开头   | `"hello".startsWith("he")`     | `true`          |
| `endsWith()`             | 是否以某字符串结尾   | `"hello".endsWith("lo")`       | `true`          |
| `indexOf()`              | 查找第一次出现位置   | `"hello".indexOf("l")`         | `2`             |
| `lastIndexOf()`          | 查找最后一次出现位置 | `"hello".lastIndexOf("l")`     | `3`             |
| `slice(start, end?)`     | 截取字符串           | `"hello".slice(1,4)`           | `"ell"`         |
| `substring(start, end?)` | 截取字符串           | `"hello".substring(1,4)`       | `"ell"`         |
| `replace()`              | 替换内容             | `"a-b-c".replace("-", "_")`    | `"a_b-c"`       |
| `replaceAll()`           | 替换所有匹配项       | `"a-b-c".replaceAll("-", "_")` | `"a_b_c"`       |
| `split()`                | 分割成数组           | `"a,b,c".split(",")`           | `["a","b","c"]` |
| `repeat()`               | 重复字符串           | `"ha".repeat(3)`               | `"hahaha"`      |
| `charAt()`               | 取某个位置字符       | `"hello".charAt(1)`            | `"e"`           |
| `at()`                   | 按索引取字符，可负数 | `"hello".at(-1)`               | `"o"`           |
| `padStart()`             | 开头补全             | `"5".padStart(3,"0")`          | `"005"`         |
| `padEnd()`               | 结尾补全             | `"5".padEnd(3,"0")`            | `"500"`         |

---

#### 2. 常见补充

::: tip `slice()` 和 `substring()` 的区别

```js
const str = "hello";

str.slice(-2); // "lo"
str.substring(-2); // "hello" 负数会按 0 处理
```

:::

当查找参数是字符串或不带 `g` 标志的正则表达式时，`replace()` 只替换第一个匹配项；使用带 `g` 标志的正则表达式时可以替换全部匹配项。

```js
"a-a-a".replace("a", "b"); // "b-a-a"
"a-a-a".replaceAll("a", "b"); // "b-b-b"
```

如果 `replaceAll()` 的查找参数是正则表达式，该正则表达式必须带有 `g` 标志，否则会抛出 `TypeError`。

`split()`

```js
const str = "Tom,18,男";
const arr = str.split(","); // ["Tom", "18", "男"]
```

### 二、数组方法（Array）

> **特点：数组方法很多**
> 其中最重要的是区分：
> **哪些会修改原数组，哪些不会修改原数组**

---

#### 1. 会修改原数组的方法

| 方法           | 作用             | 示例                      |
| -------------- | ---------------- | ------------------------- |
| `push()`       | 尾部添加         | `arr.push(4)`             |
| `pop()`        | 删除最后一个     | `arr.pop()`               |
| `unshift()`    | 头部添加         | `arr.unshift(0)`          |
| `shift()`      | 删除第一个       | `arr.shift()`             |
| `splice()`     | 任意位置增删改   | `arr.splice(1, 2)`        |
| `sort()`       | 排序             | `arr.sort((a,b)=>a-b)`    |
| `reverse()`    | 反转             | `arr.reverse()`           |
| `fill()`       | 填充数组         | `arr.fill(0)`             |
| `copyWithin()` | 复制数组内部元素 | `arr.copyWithin(1, 0, 2)` |

示例

```js
const arr = [1, 2, 3];

const lengthAfterPush = arr.push(4); // 4
console.log(arr); // [1, 2, 3, 4]

const last = arr.pop(); // 4
console.log(arr); // [1, 2, 3]

const lengthAfterUnshift = arr.unshift(0); // 4
console.log(arr); // [0, 1, 2, 3]

const first = arr.shift(); // 0
console.log(arr); // [1, 2, 3]
```

`splice()` 非常重要

```js
const arr = [1, 2, 3, 4];

const removed = arr.splice(1, 2); // [2, 3]
console.log(arr); // [1, 4]

const insertedResult = arr.splice(1, 0, 99); // []
console.log(arr); // [1, 99, 4]

const replaced = arr.splice(1, 1, 88); // [99]
console.log(arr); // [1, 88, 4]
```

---

#### 2. 不会修改原数组的方法

| 方法              | 作用                     | 示例                             |
| ----------------- | ------------------------ | -------------------------------- |
| `slice()`         | 截取数组                 | `arr.slice(1,3)`                 |
| `concat()`        | 拼接数组                 | `arr.concat([4,5])`              |
| `includes()`      | 是否包含元素             | `arr.includes(2)`                |
| `indexOf()`       | 查找第一次出现位置       | `arr.indexOf(2)`                 |
| `lastIndexOf()`   | 查找最后一次出现位置     | `arr.lastIndexOf(2)`             |
| `find()`          | 找到第一个满足条件的元素 | `arr.find(x=>x>2)`               |
| `findIndex()`     | 找到第一个满足条件的索引 | `arr.findIndex(x=>x>2)`          |
| `findLast()`      | 从后往前找元素           | `arr.findLast(x=>x>2)`           |
| `findLastIndex()` | 从后往前找索引           | `arr.findLastIndex(x=>x>2)`      |
| `forEach()`       | 遍历                     | `arr.forEach(x=>console.log(x))` |
| `map()`           | 映射，返回新数组         | `arr.map(x=>x*2)`                |

### 三、对象方法（Object）

> **数组是对象的一种特殊形式**
> 本文介绍的对象操作主要使用 `Object.xxx()` 这样的**静态方法**；普通对象也可能继承 `Object.prototype` 上的方法。

---

#### 1. 常用对象方法

| 方法                                | 作用               | 示例                                     |
| ----------------------------------- | ------------------ | ---------------------------------------- |
| `Object.keys(obj)`                  | 获取对象自身可枚举字符串属性的键 | `Object.keys(user)`                      |
| `Object.values(obj)`                | 获取对象自身可枚举字符串属性的值 | `Object.values(user)`                    |
| `Object.entries(obj)`               | 获取对象自身可枚举字符串属性的键值对数组 | `Object.entries(user)`               |
| `Object.fromEntries(iterable)`      | 将可迭代对象提供的键值对转换为对象 | `Object.fromEntries([["a",1]])`       |
| `Object.assign(target, ...sources)` | 将源对象自身可枚举属性浅复制到目标对象，修改并返回目标对象 | `Object.assign({}, a, b)` |
| `Object.hasOwn(obj, key)`           | 判断是否有自身属性 | `Object.hasOwn(user, "name")`            |
| `Object.freeze(obj)`                | 浅冻结对象自身属性；嵌套对象不会自动冻结 | `Object.freeze(user)`               |
| `Object.seal(obj)`                  | 浅密封对象：禁止新增或删除自身属性，但已有可写数据属性仍可修改 | `Object.seal(user)` |
| `Object.preventExtensions(obj)`     | 禁止新增自身属性并阻止重新设置原型；已有属性通常仍可修改或删除 | `Object.preventExtensions(user)` |
| `Object.defineProperty()`           | 定义属性           | `Object.defineProperty(obj, "x", { value: 1 })` |
| `Object.defineProperties()`         | 批量定义属性       | `Object.defineProperties(obj, { x: { value: 1 } })` |
| `Object.create(proto)`              | 指定原型创建对象   | `Object.create(proto)`                   |
| `Object.getPrototypeOf(obj)`        | 获取原型           | `Object.getPrototypeOf(obj)`             |
| `Object.setPrototypeOf(obj, proto)` | 设置原型           | `Object.setPrototypeOf(obj, proto)`      |
| `Object.is(a, b)`                   | 按 SameValue 语义比较两个值；`NaN` 等于自身，并区分 `+0` 与 `-0` | `Object.is(NaN, NaN)` |

---

#### 2. 最常用的对象方法示例

`Object.keys / values / entries`

```js
const user = { name: "Tom", age: 18 };

Object.keys(user); // ["name", "age"]
Object.values(user); // ["Tom", 18]
Object.entries(user); // [["name", "Tom"], ["age", 18]]
```

`Object.fromEntries`

```js
const arr = [
  ["name", "Tom"],
  ["age", 18],
];
const obj = Object.fromEntries(arr);
// { name: "Tom", age: 18 }
```

`Object.assign`

```js
const a = { x: 1 };
const b = { y: 2 };

const c = Object.assign({}, a, b);
// { x: 1, y: 2 }
```

也常用对象展开语法；它会把源对象自身可枚举属性浅复制到新对象：

```js
const c = { ...a, ...b };
```

`Object.hasOwn`

```js
const user = { name: "Tom" };

Object.hasOwn(user, "name"); // true
```

---

#### 3. 对象常用操作（不是方法，但很常见）

| 写法             | 作用             |
| ---------------- | ---------------- |
| `obj.name`       | 访问属性         |
| `obj["name"]`    | 按键访问属性     |
| `obj.age = 18`   | 新增/修改属性    |
| `delete obj.age` | 尝试删除对象自身属性并返回布尔值；不可配置属性无法删除，严格模式下会抛出 `TypeError` |
| `"name" in obj`  | 判断对象自身或原型链上是否存在该属性；只检查自身属性时使用 `Object.hasOwn()` |
| `for...in`       | 遍历对象自身及原型链上的可枚举字符串属性；不遍历 Symbol 属性 |
| `{ ...obj }`     | 浅拷贝对象       |

示例

```js
const obj = { name: "Tom", age: 18 };

console.log(obj.name); // Tom
console.log("name" in obj); // true

delete obj.age;
```

- `Object.values()`

- `Object.fromEntries()`

### 四、三类方法的重点区别

#### 1. 字符串

- **不会修改原字符串；具体返回值由所用方法决定**
- 常做：截取、查找、替换、分割、去空格

#### 2. 数组

- 方法最多
- 一定要区分：
  - **改原数组**
  - **不改原数组**

#### 3. 对象

- 常用 `Object.xxx()` 静态方法
- 常做：取键值、合并、判断属性、冻结对象

### 五、最值得背的速查版

#### 字符串最常用

```js
const text = " hello ";
```

```js
const numbers = [1, 2, 3];

numbers.shift();

numbers.includes(2);
```
